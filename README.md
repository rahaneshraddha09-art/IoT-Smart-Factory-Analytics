# Smart Factory Analytics & Predictive Maintenance

## 📊 Project Overview

This project analyzes smart factory machine data to monitor machine performance, energy consumption, maintenance status, and failure risk.

The project uses Python for data analysis and Power BI for interactive dashboard visualization.

## 🎯 Objectives

- Analyze machine performance
- Monitor sensor parameters
- Analyze energy consumption
- Study machine maintenance status
- Identify failure risk patterns
- Support predictive maintenance decisions

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Jupyter Notebook

## 📁 Dataset

The dataset contains 1000 machine records with parameters such as:

- Machine ID
- Timestamp
- Temperature
- Vibration
- Pressure
- Energy Consumption
- Operating Hours
- Machine Status
- Maintenance Status
- Failure Risk

## 📈 Dashboard

The Power BI dashboard provides:

- Total Machines
- Average Temperature
- Total Energy Consumption
- Total Operating Hours
- Machine Status Distribution
- Failure Risk Distribution
- Maintenance Status Analysis
- Temperature Trend
- Machine-wise Energy Analysis
- Energy vs Operating Hours Analysis

## 🔄 Project Workflow

Dataset → Data Cleaning → Exploratory Data Analysis → Python Analysis → Power BI Dashboard → Predictive Maintenance Insights

## 📌 Project Outcome

The project provides an interactive analytics solution for monitoring machine performance and identifying maintenance and failure-risk patterns in a smart factory environment.
